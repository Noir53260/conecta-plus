# Conecta+ — Página de planes para GitHub Pages

Página estática profesional hecha con:
- `index.html`
- `styles.css`
- `script.js`
- carpeta `assets/`

## Publicarla en GitHub Pages

1. Crea un repositorio en GitHub.
2. Sube estos archivos conservando la estructura.
3. Ve a **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/ (root)`.
6. Guarda y espera a que GitHub genere la dirección pública.
